Headings and Paragraphs

Headings and paragraphs are BLOCK elements

Headings

There are 6 levels of heading. Headings are logical marked. DO not skip levels. If you want to change the size of a heading, don't change its level-change the CSS.

Paragraphs

Paragraphs contain the body text of a web page. You cannot put another blocks element inside a paragraph.

Special Characters

While HTML support many named special character like &(#174); , XML only supports 5 namely: " '&". So to keep you HTML compliant you need to use numbers for all the others.'
